# EduGenie - Google Gemini Powered Learning Assistant

A FastAPI-based educational assistant with:
- Question & Answer
- Topic Explanation
- Quiz Generation
- Text Summarization
- Personalized Learning Path

## VS Code Project Structure

EduGenie/
├── main.py
├── requirements.txt
├── .env
├── .gitignore
├── README.md
├── templates/
│   └── index.html
└── static/
    ├── style.css
    └── script.js

Add your Gemini API key in `.env` before running the project.
